这是一个整合了多功能的原神启动模组

功能描述
1.找到原神游戏本体时直接启动原神
2.找不到原神游戏本体时寻找米哈游启动器，找到米哈游启动器时启动启动器
3.原神游戏本体和米哈游启动器都找不到时，自动下载原神启动器安装包并运行

模组缺陷
1.本模组使用搜索“Yuanshen.exe”文件寻找原神，使用搜索“miHoYo Launcher”文件夹后在其子树搜索“launcher“
		找到启动器，如果上述三个文件名被更改或者在电脑中有其他同名文件，可能会导致无法正确搜索，后者严重时
		导致游戏崩溃。
2.本模组使用多线程全盘搜索，如果你的电脑使用机械硬盘或者硬盘容量大，会延长搜索时间，体现在卡在加载页面不动的
		情况，属于正常状况。

可能的BUG
由于测试需要模拟三种不同的环境，而我并没有安装虚拟机，整个模组没有试过在三个环境下来回切换测试，bug在所难免。

重要信息
1.靠访问网站https://ys-api.mihoyo.com/event/download_porter/link/ys_cn/official/pc_backup319直接下载启动器安装包
2.下载下来的安装包存放在"版本文件夹/Temporary"文件夹下，名字类似"launcher_20260624_065517.exe"，"_20260624_065517"为时间戳
